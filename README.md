# WHAT-MAKES-A-MOVIE-SUCCESSFUL-
Looking into factors that affect a movies success in the boxoffice. 

Began investigation by downloading dataset and exploring excel files. Focused on movies.metadata file as this contains the most information for analysis. 

Began cleaning the data by removing redundant variables. Variables such as adult and video were removed due to a majority FALSE value were removed due to little explanatory power. Other variables such as homepage were also removed as they contained majority missing values. 

Then used the filter tool on excel to identity observations with missing values.
